## What changed from earlier planning

We no longer use a claimed 50–60% or 30% probability as if it were an OpenAI statistic. No public dataset supports that precision.

We also no longer treat fixed thresholds such as 5+ repositories, 1k+ stars for an anchor, or a merged PR as official requirements. They are useful internal milestones only.

## Evidence discipline

A public-source reproduction is not external validation.
A self-owned demo is not third-party adoption.
A maintainer reply is not an endorsement unless it actually states that.
A no-response report is not an official rejection.
A projected API budget is not evidence of need.
